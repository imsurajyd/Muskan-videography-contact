# 🎬 Muskan Videography & Photography

A luxury, modern, and cinematic photography & videography portfolio website built with **React**, **Tailwind CSS v4**, and **React Icons**.

---

## ✨ Features

- **Cinematic Dark Theme**: Designed with a luxury dark mode and gold accent colors (`--gold`).
- **Fully Responsive**: Optimized for mobile devices, tablets, and desktop screens.
- **Fast & Lightweight**: Pure CSS animations and clean component layout (Zero heavy animation overhead).
- **Direct WhatsApp Integration**: Pre-filled booking and inquiry message template for instant customer chats.
- **Service Showcase**: Grid layout featuring wedding shoots, drone videography, pre-weddings, and live streaming.
- **Contact & Booking System**: One-tap phone dialing, Google Maps location integration, and contact cards.

---

## 🛠️ Tech Stack

- **Frontend Framework**: [React.js](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)

🚀 Local Development Setup
Follow these steps to set up and run the project locally:

1. Clone the Repository
Bash
git clone [https://github.com/your-username/muskan-videography.git](https://github.com/your-username/muskan-videography.git)
cd muskan-videography
2. Install Dependencies
Bash
npm install
3. Run Development Server
Bash
npm run dev
Open http://localhost:5173 in your browser.

⚡ Deployment
Deploy on Vercel
Bash
npm run build
You can deploy this project instantly using Vercel or Netlify by connecting your GitHub repository.
